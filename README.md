# Raynauld Ronoh — AI Engineer Portfolio

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Edit `index.html` and `styles.css` to personalize the content.

## Before publishing
- Replace the profile placeholder with your real photo. Create an `images` folder, add `profile.jpg`, and replace the profile placeholder block in `index.html` with:
  `<img src="images/profile.jpg" alt="Raynauld Ronoh">`
- Replace `YOUR_EMAIL@example.com` and all social profile placeholders with your real links.
- Add GitHub repository/demo links to the four project cards.
- Add verified accomplishments, metrics, responsibilities, and the employer name for the March 2023–March 2024 Junior AI Engineer role.
- Check every listed technology against your actual experience.
- The project descriptions are portfolio starter copy based on the AI project themes discussed; revise them to reflect what you actually built and avoid claiming unmeasured results.

## Files
- `index.html` — page structure and editable content
- `styles.css` — responsive visual styling


## Resume PDF download
The website includes a Resume section with a direct PDF download and a preview link. The PDF is stored at `resume/Raynauld_Ronoh_AI_Engineer_Resume.pdf`. If you update your resume, replace that file while keeping the same filename, or update both links in `index.html`.
